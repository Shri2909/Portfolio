# Fonts

Fraunces (roman and italic), subset and embedded as woff2 in `src/fonts/`. Licence: SIL Open Font License 1.1 (OFL); the licence text is in `src/fonts/OFL.txt`. Total font weight in `dist/` is under the 90 KB budget (about 73 KB). No external font host is used or requested; the system serif is the fallback.
